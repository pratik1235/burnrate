# Ignore Directory Usage

When you need to create scratchpad files, run experiments, download temporary artifacts, or save research notes that should **not** be committed to the repository, you MUST save them inside the `ignore/` directory at the root of the project.

This directory has been explicitly added to `.gitignore` to keep the working tree clean and prevent accidental commits of transient data or local configurations.
